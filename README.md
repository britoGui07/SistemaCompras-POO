# Sistema de Compras

Sistema de compras desenvolvido como atividade da disciplina de **Programação Orientada a Objetos (POO)**.

O projeto foi desenvolvido em dupla com o objetivo de praticar os principais conceitos de POO apresentados em aula, utilizando Java.

## Sobre o projeto

O sistema permite realizar operações básicas relacionadas a clientes, produtos e compras, utilizando uma estrutura simples para representar as entidades e as regras do sistema.

O projeto foi desenvolvido exclusivamente para fins acadêmicos.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos

## Estrutura do projeto

O sistema foi organizado utilizando diferentes classes e camadas, buscando separar as responsabilidades de cada parte da aplicação.

- **Model** — classes que representam as entidades do sistema.
- **BLL** — regras e operações relacionadas ao funcionamento do sistema.
- **DAO** — responsável pela comunicação e manipulação dos dados.
- **UI** — interação do sistema com o usuário.

## Objetivo

Praticar os conceitos de Programação Orientada a Objetos aprendidos durante as aulas, como:

- Classes e objetos
- Encapsulamento
- Atributos e métodos
- Construtores
- Relacionamento entre classes
- Organização do código em camadas
